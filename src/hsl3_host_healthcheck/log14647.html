1. Description

This is a description for the module.

2. Inputs

No. Name Initialisation Description
1 Host Name or IP
Host name or IP address to perform health check on.
2 Host Port 80
Port number to perform health check on.
3 Host use SSL (1=True, 0=False) 0
Indicates whether to use SSL for the health check (1=True, 0=False).
4 Host Path
Path to execute a HTTP request and check if the host is reachable.
5 HTTP Request Parameters {}
Parameters to include in the HTTP request {} or {'key1': 10, 'key2': 'value2'} format.
6 Healthcheck Benchmark
Benchmark value for the health check on the http(S).
7 MAC Address
MAC address of the host.
8 Healthcheck Frequency 60
Frequency of the health check in seconds.
9 Trigger Wake-on-LAN 0
Indicates whether to trigger Wake-on-LAN (1=True, 0=False).
10 Enable Logging 0
Enable diagnostic Syslog messages and debugging (1=True, 0=False). Errors and critical messages are always logged.

3. Outputs

No. Name Initialisation SBC Description
1 HTTP Health 0 s
Indicates whether the HTTP health check succeeds (1=True, 0=False).
2 Response Time 0.0 s
Response time of the Ping health check in milliseconds.
3 Health Check Error s
Error message for the most recent HTTP health check, or empty when successful.
s = send, sbc = send by change
