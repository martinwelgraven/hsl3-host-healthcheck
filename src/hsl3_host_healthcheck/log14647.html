1. Description

A hsl3 module for network detection. With several health check mechanisms.

HTTP Health reflects the result of the following checks in order of precedence:
- if path (minimal '/') and benchmark are provided, the benchmark result
- if only path is provided, the HTTP statuscode result
- A UDP port scan (UDP port != 0)
- A TCP port scan (TCP port != 0)

If a MAC Address is provided, a Wake-on-LAN can be triggerred
Note
Errors and critical messages are always logged.

0.1.0 First working version.
0.1.1 a test version

2. Inputs

No. Name Initialisation Description
1 Host Name or IP
Host name or IP address to check.
2 UDP Port 7
UDP port to check on (0 for no check).
3 TCP Port 80
TCP port to check on (0 for no check).
4 Host use SSL (1=True, 0=False) 0
Indicates whether to use SSL for the health check (1=True, 0=False).
5 Host Path [o]
Path to execute a HTTP request and check if the host is reachable.
6 HTTP Request Parameters [o] {}
Parameters to include in the HTTP request {} or {'key1': 10, 'key2': 'value2'} format.
7 Benchmark [o]
Benchmark value to find in the response of a http(S) request.
8 MAC Address [o]
MAC address of the host.
9 Healthcheck Frequency 60
Frequency of the health check in seconds (0 for no periodic check).
10 Trigger Wake-on-LAN 0
Trigger for Wake-on-LAN. Any input will trigger the action.
11 Enable Logging (1=True, 0=False) 0
Enable syslog messages and debugging (1=True, 0=False).

3. Outputs

No. Name Initialisation SBC Description
1 HTTP Health 0 s
Indicates whether the HTTP health check succeeds (1=True, 0=False).
2 Response Time 0.0 s
Response time of the Ping health check in milliseconds.
3 HTTP Response s
HTTP response if path or benchmark filled. Format '|'
4 Health Check Error s
Error message for the most recent HTTP health check, or empty when successful.
s = send, sbc = send by change
